# Aula · Practica a tu ritmo

A Spanish-language exam practice app for 5th grade. Starts with Castellano: diptongos and hiatos, syllables, accents, and personal pronouns. English, Mathematics, and Valenciano are prepared for future content.

- 76 questions across four practice sets
- Immediate feedback and explanations
- Mixed 20-question review
- Final score, answer review, and retry incorrect answers
- Shuffled questions and choices on each attempt
- Browser-local progress; no account or backend required

## Run locally

Serve this directory with any static web server, for example `python3 -m http.server 8000`, then visit http://localhost:8000.

## Edit content

Question banks live in `data.js`, the practice flow in `app.js`, and presentation in `style.css`.

## Deployment

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` are published automatically.
